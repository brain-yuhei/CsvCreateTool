## 機能詳細

### CSVファイル管理画面 ①

メッセージを表示する

- [ ] 入力なし：なし

- [ ] 出力あり：メッセージ

#### 実装方法：詳細 ①

- CsvUploadControllerクラス
  - モデルにメッセージが格納されている場合は表示する

### CSVファイル管理画面 ②

モーダル画面を表示する

- [ ] 入力なし：なし

- [ ] 出力あり：モーダル画面

#### 実装方法：詳細 ②

- modal.jsクラス
  - モーダル画面を表示する

### CSVファイル管理画面 ③

押下時にCSV編集メニュー画面へ画面遷移する。

- [ ] 入力なし：なし

- [ ] 出力あり：CSV編集メニュー画面

### CSVファイル管理画面 ④

押下時にCSV管理表内のデータをwrk_keiroテーブルに保存する

- [ ] 入力なし：なし

- [ ] 出力あり：CSV管理表

#### 実装方法：詳細 ④

- CsvUploadControllerクラス
  - wrk_keiroデータの削除処理を呼び出す
  - wrk_keiroデータの保存処理を呼び出す

- CsvDownloadServiceクラス
  - wrk_keiroデータの削除する。
  - CSV管理表のデータをwrk_keiroへ保存する。

### CSVファイル管理画面 ⑤

wrk_keiroテーブルのデータを表示する

- [ ] 入力なし：なし

- [ ] 出力あり：CSV管理表

#### 実装方法：詳細 ⑤

- CsvUploadControllerクラス
  - wrk_keiroデータの取得処理を呼び出す

- CsvDownloadServiceクラス
  - 選択年月を使ってwrk_keiroデータを取得する。

### CSVファイル管理画面 ⑥

押下時に全選択と全選択解除する

- [ ] 入力あり：チェックの有無

- [ ] 出力あり：チェックの有無

### CSVファイル管理画面 ⑦

選択時にmst_keiroテーブルのpayeecontentから同じデータを検索しCSV管理表の他項目を自動反映する

- [ ] 入力なし：プルダウン選択

- [ ] 出力あり：mst_keiroデータ

#### 実装方法：詳細 ⑦

- CsvUploadControllerクラス
  - CSV管理表への表示用データ生成処理を呼び出す

- WrkKeiroServiceクラス
  - 選択した支払先・内容のデータでmst_keiroテーブルからデータ取得する。
